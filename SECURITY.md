# Security policy

Please report suspected vulnerabilities privately through GitHub's **Report a
vulnerability** flow for this repository. Do not include credentials, prompts, model
outputs, customer data, or exploit details in a public issue.

We aim to acknowledge actionable reports within seven days. Response and remediation
timing depend on severity and maintainer availability; this is an open-source project,
not a managed incident-response service.

Security fixes target the current release line. Older releases may receive guidance
rather than patches. Reports should include the affected version, impact, minimal
reproduction, and whether disclosure is already public.

The project treats model output, tool arguments, workspace content, and retrieved data
as untrusted. The detailed trust boundaries and known limitations are documented in
[docs/security.md](docs/security.md). General support requests belong in the channels
listed in [SUPPORT.md](SUPPORT.md).
