# Support

Start with the [getting-started guide](docs/getting-started.md), then run:

```bash
agnoclaw doctor --json
agnoclaw explain ERROR_CODE
agnoclaw support-bundle --output agnoclaw-support.json
```

Use GitHub Discussions for setup questions and design conversations. Use a GitHub issue
for a reproducible bug or feature request. Search existing threads first and include
the agnoclaw/Python/Agno versions, runtime profile, minimal reproduction, expected and
actual behavior, and a redacted support bundle when useful.

Never post API keys, environment values, filesystem paths, prompts, model outputs,
customer data, or private repository content. Maintainer support is best-effort; there
is no guaranteed response time or private production-support contract.
